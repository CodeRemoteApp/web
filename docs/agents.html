Coding agents

Follow every Claude Code session on your computer from your iPhone, answer its permission prompts and questions there, and get a notification when it needs you.

The Agents tab and notifications are part of Code Remote Pro, and need a recent coderemote on the computer: run coderemote update and start coderemote up again if the app says so.

Set up

Once per computer, with Claude Code installed:

$ coderemote setup claude

This installs the Code Remote plugin into Claude Code (the same as /plugin install coderemote --marketplace CodeRemoteApp/coderemote inside Claude Code). Claude Code sessions you start afterwards, in a folder shared with coderemote up, show up in the app. Sessions already running appear after you restart them. To undo it: coderemote setup claude --remove.

The plugin does nothing when no coderemote is running, or when the session's folder isn't shared: Claude Code then works exactly as without it.

The Agents tab

Lists the sessions on the machine, grouped into Needs You (waiting for an answer), Working, Idle and Ended; the tab shows how many need you. Open one to see what it did: your prompts, Claude's replies, and each tool it ran. Commands show with their output, file edits as the lines they change (tap for the whole change or the file), and reads open the file.

A session started in a terminal in the app has Open in Terminal, to type into it directly. Sessions you started on the computer show the same timeline.

Sessions live in coderemote's memory: stopping coderemote up clears the list, and ended sessions disappear after a day.

Answer from the phone

When Claude asks for permission to run something, or asks you a question, a card appears at the bottom of the session:

  • Allow or Deny. The ⋯ menu has the same "always allow" choices Claude Code offers on the computer, and Deny with Message to tell Claude what to do instead.
  • For a question, tap an answer, or Other… to type one.

The prompt stays open on the computer too. Whichever side answers first wins: answer at the computer and the card (and its notification) goes away on the phone. A prompt nobody answers from the phone within an hour is left to the computer.

Notifications

Turn them on per computer in the machine's info (hold it in the machine list, or Machine Info in a tab's menu): Needs an answer and Finished a long task (one that took a minute or more), with a test button.

Long-press a permission notification to Allow or Deny without opening the app (after Face ID); a single question offers its answers the same way. Nothing is sent while you're using the computer (on a Mac) or have the machine open in the app.

How it works

The plugin runs coderemote hook for each Claude Code event (a prompt, a tool call, a reply, a permission prompt). It hands the event to the coderemote sharing the session's folder, on the same computer, authenticated by a secret that never leaves it. A permission prompt waits there for an answer from the phone while Claude Code shows its own prompt as usual.

Notifications go from your computer through a relay that adds the app's Apple push key; their content is encrypted for your iPhone, so neither the relay nor Apple can read it, and the relay keeps nothing. See the privacy policy.
