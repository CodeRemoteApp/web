Setup

One command on the computer, one scan on the phone.

Requirements

  • A Mac with Node.js 20 or newer. Linux is expected to work but isn't tested yet.
  • A GitHub or Microsoft account, used to sign in to Microsoft Dev Tunnels.
  • The Code Remote app on your iPhone.

You don't need SSH, open ports, a VPN or VS Code.

1. Install the CLI

$ npm install -g coderemote

Check it worked with coderemote help.

2. Share a folder

Go to the folder you want to reach from your phone and start the agent:

$ cd ~/projects/my-app
$ coderemote up

The first run sets itself up:

  1. It downloads Microsoft's Dev Tunnels CLI into ~/.coderemote/bin (once, signature checked).
  2. It opens your browser to sign in with GitHub. To use a Microsoft account instead, run coderemote login --microsoft before up.
  3. It creates a private tunnel for this computer and prints a QR code.
✔ Starting agent
✔ Checking dev tunnels sign-in
✔ Connecting to the relay

  Sharing: /Users/you/projects/my-app
  Access:  sign-in required as you (GitHub)

  Web:  https://…devtunnels.ms/#token=…
  App:  vsremote://pair?url=…&token=…

  [QR code]

3. Pair your iPhone

Scan the QR code with the iPhone Camera, or tap + in the app and scan it there. The app then asks you to sign in through the system browser with the same GitHub or Microsoft account the computer uses. Passkeys and "Sign in with Google" work.

That's it. Files, Git and Terminal for the shared folder are now on your phone.

The QR code and the links contain your access token. Don't post them anywhere. If one leaks, run coderemote rotate-token.

Everyday use

Keep the terminal open

coderemote up runs in the foreground. Press Ctrl+C or close the window to stop sharing; terminal sessions end with it.

Keep the computer awake

A sleeping Mac can't answer the phone. On a laptop, start the agent under caffeinate so the Mac stays awake while it runs:

$ caffeinate -i coderemote up

Pairing survives restarts

The tunnel URL and token stay the same between runs, so a paired phone reconnects on its own the next time you run coderemote up. You only scan again after rotate-token.

Update or uninstall

coderemote up tells you when there's a newer version, under the pairing links.

# update to the latest release
$ coderemote update

# the same, for versions without the update command
$ npm install -g coderemote@latest

# remove it, with its token and tunnel settings
$ coderemote stop --all
$ npm uninstall -g coderemote
$ rm -rf ~/.coderemote
