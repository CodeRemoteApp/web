Introduction

Your computer, from your iPhone: files, git, a real terminal and your dev servers. One command on the computer, one scan on the phone.

What it is

Code Remote has two parts: the coderemote command-line tool on your computer, and the iPhone app. You don't need SSH, open ports, a VPN or a desktop app. Not sure it fits? See how it compares with Tailscale, Termius and Orca.

How it works

  1. Start the agent. Run coderemote up in a project folder (or npx coderemote up without installing). A small agent starts on your computer, listening on 127.0.0.1 only.
  2. It connects outward. The agent publishes itself through a private Microsoft Dev Tunnel. Nothing on your network has to be opened, and it works behind NAT, firewalls and hotel Wi-Fi.
  3. Pair your phone. Scan the QR code. Only your GitHub or Microsoft account gets through the relay, every request also needs the pairing token, kept in the iPhone Keychain, and the QR code carries your computer's key so the app encrypts everything end to end: the relay only forwards ciphertext.
