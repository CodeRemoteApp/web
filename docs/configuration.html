Configuration

There's nothing to configure to get started. This page is for when you want to know what's going on.

Who can get in

By default a request has to pass two checks:

  1. Your account. The tunnel is private: the Dev Tunnels relay lets through only the GitHub or Microsoft account that ran coderemote up.
  2. The pairing token. The agent then checks the random token from the QR code, kept in the iPhone Keychain.

With coderemote up --allow-anonymous the first check is skipped and the token alone grants access. Either way, files and git stay inside the shared folder; a terminal is a real shell with your user's permissions.

Files on your computer

Everything lives in ~/.coderemote, readable only by you:

PathWhat it holds
config.jsonThe access token and the id of this computer's tunnel. Keeping it keeps every pairing.
bin/The Dev Tunnels CLI downloaded on first run.
agents/One entry per running agent, so status, kill and stop can find it.

Deleting the folder resets Code Remote: the next up creates a new token and tunnel, and every device has to pair again.

Environment variables

VariableWhat it does
CODEREMOTE_DEVTUNNELPath to a devtunnel binary to use. Otherwise one on your PATH is used, then the downloaded copy.
CODEREMOTE_CODEPath to VS Code's code command, for up --web. Otherwise code on your PATH.

The tunnel

Each computer has one tunnel. Its URL stays the same between runs, and up renews it each time so it doesn't expire. Share one folder at a time; to reach several projects, share their parent folder and the Git tab finds every repository inside it.

Troubleshooting

"Port 31580 is already in use"

Another agent or program holds the port. coderemote status shows agents; for anything else, see what holds it:

$ lsof -nP -iTCP:31580 -sTCP:LISTEN

Stop it, run coderemote stop --all, or pick another port with --port.

The phone can't connect

Check that coderemote up is still running and the computer is awake and online. Make sure the phone signed in with the same account the computer uses (shown on the Access: line).

The sign-in expired

up notices and opens the browser again. Without a browser, run coderemote login --device-code.

Installing on Linux fails

The terminal support compiles on install and needs python3, make and a C++ compiler (build-essential on Debian and Ubuntu). Signing in needs libsecret-1-0.

Still stuck? See Support.
