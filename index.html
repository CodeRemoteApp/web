Your computer, in your pocket.

Browse files, review and commit with git, and run a real terminal on your dev machine from your iPhone. One command on the computer, one QR scan on the phone. No SSH keys, no port forwarding, no VPN.

Get started View on npm iPhone app coming soon to the App Store. 
# on your computer
$ npm install -g coderemote
$ cd ~/projects/my-app && coderemote up
# scan the QR code with your iPhone. Done.▍

Everything you need to keep working.

Files

Browse, open, edit, create, rename and delete files in the folder you share.

Git

See changes and diffs, stage, commit, pull, push and read history, across every repository in the folder.

Terminal

A real shell with a key bar for Ctrl, Tab, Esc and arrows. Sessions keep running while your phone sleeps, so long builds and coding agents survive.

How it works

  1. Start the agent

    Run coderemote up in a project folder. A small agent starts on your computer, listening on 127.0.0.1 only.

  2. It connects outward

    The agent publishes itself through a private Microsoft Dev Tunnel. Nothing on your network has to be opened, and it works behind NAT, firewalls and hotel Wi-Fi.

  3. Pair your phone

    Scan the QR code. Only your GitHub or Microsoft account gets through the relay, and every request also needs the pairing token, kept in the iPhone Keychain.

Private by design.

No servers of ours

Your phone talks to your computer. Code Remote runs no backend and has no accounts.

Nothing collected

No analytics, no tracking, no ads. Your files and commands never reach us.
