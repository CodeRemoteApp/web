# Translation glossary

Never translate: Code Remote, coderemote, GitHub, TestFlight, Dev Tunnels / Microsoft Dev Tunnel,
VS Code, Claude Code, Codex, iPhone, npm, npx, Homebrew, QR, SSH, VPN, AGPL, git, commands,
flags, file paths, ports, key names (Ctrl, Tab, Esc).

Translate in the page voice: friendly, direct, second person ("you"), short sentences.
Keep inline tags (`<code>`, `<a href>`, `<kbd>`, `<em>`) exactly as in the English string;
only the words between them change. Keep `&amp;` style entities. Never put a `"` in an
attribute translation (use `&quot;`).
