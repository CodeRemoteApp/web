Code Remote frente a las formas habituales de entrar.

Para llegar a tu máquina de desarrollo desde un teléfono, la mayoría de las herramientas quieren que descargues una app en el ordenador, configures una VPN o configures SSH. Code Remote necesita un comando y un escaneo de QR.

npx coderemote up

Necesita Node.js 22 o posterior. ¿Sin Node? El script de instalación obtiene uno solo para coderemote. La primera ejecución te pide iniciar sesión una vez con GitHub o Microsoft.

Por qué Code Remote

  • El camino más corto. Un comando y un escaneo. Las demás necesitan dos o tres instalaciones, una cuenta en cada lado, y claves o ajustes de red.
  • Nada que mantener. Sin VPN que mantener conectada, sin servidor SSH que proteger, sin claves que rotar, sin app de escritorio que actualizar.
  • Hecho para el teléfono. Un explorador de archivos, revisión de git, barra de teclas para el terminal y vistas previas de un toque, en lugar de un terminal apretado en una pantalla pequeña.
  • Privado por diseño. El agente escucha solo en 127.0.0.1 y no hay ningún servidor de Code Remote en medio. Lee cómo funciona.

Tailscale y Termius son la elección correcta si administras muchas máquinas o servidores, y Code Remote no los sustituye para eso. Orca es donde ejecutas agentes en tu escritorio, y Code Remote es cómo llegas a tu máquina cuando estás lejos de ella, así que ambas pueden convivir.

Cuándo otra herramienta encaja mejor

  • Necesitas el escritorio completo. Code Remote es para el trabajo de desarrollo: archivos, git, terminal, servidores de desarrollo. Para una app de diseño o un instalador gráfico, usa una app de escritorio remoto.
  • Ya usas VPN y SSH en todas partes. Si ya lo tienes montado y te gusta, una app de terminal sobre eso funciona bien. Code Remote es para cuando prefieres no configurar nada.
  • No es un iPhone. La app de Code Remote es para iPhone. Por ahora, cualquier otro dispositivo tiene que usar las herramientas de arriba (¿la quieres en Android?).

Lo que sigue siendo sencillo

El agente solo escucha en 127.0.0.1 y se publica a través de un Microsoft Dev Tunnel privado. Solo pasa tu cuenta de GitHub o Microsoft, todo lo que va entre el teléfono y el ordenador está cifrado de extremo a extremo con la clave del código QR, y cada teléfono inicia sesión con su propia clave de su Secure Enclave.
