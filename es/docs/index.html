Introducción

Tu ordenador, desde tu iPhone: archivos, git, un terminal real y tus servidores de desarrollo. Un comando en el ordenador, un escaneo en el teléfono.

Qué es

Code Remote tiene dos partes: la herramienta de línea de comandos coderemote en tu ordenador y la app para iPhone. No necesitas SSH, puertos abiertos, VPN ni app de escritorio. ¿No estás seguro de que encaje? Mira cómo se compara con Tailscale, Termius y Orca.

Cómo funciona

  1. Inicia el agente. Ejecuta coderemote up en la carpeta de un proyecto (o npx coderemote up sin instalar). Un pequeño agente arranca en tu ordenador, escuchando solo en 127.0.0.1.
  2. Se conecta hacia fuera. El agente se publica a través de un Microsoft Dev Tunnel privado. No hay que abrir nada en tu red, y funciona detrás de NAT, firewalls y el wifi del hotel.
  3. Empareja tu teléfono. Escanea el código QR. Solo tu cuenta de GitHub o Microsoft pasa por el relé, cada solicitud también necesita el token de emparejamiento, guardado en el llavero del iPhone, y el código QR lleva la clave de tu ordenador para que la app lo cifre todo de extremo a extremo: el relé solo reenvía datos cifrados.
