Agentes de programación

Sigue desde tu iPhone cada sesión de Claude Code de tu ordenador, responde allí a sus solicitudes de permiso y preguntas, y recibe una notificación cuando te necesita.

La pestaña Agents y las notificaciones forman parte de Code Remote Pro, y necesitan un coderemote reciente en el ordenador: ejecuta coderemote update y vuelve a iniciar coderemote up si la app lo indica.

Configuración

Una vez por ordenador, con Claude Code instalado:

$ coderemote setup claude

Esto instala el plugin de Code Remote en Claude Code (igual que /plugin install coderemote --marketplace CodeRemoteApp/coderemote dentro de Claude Code). Las sesiones de Claude Code que inicies después, en una carpeta compartida con coderemote up, aparecen en la app. Las sesiones que ya estaban en marcha aparecen tras reiniciarlas. Para deshacerlo: coderemote setup claude --remove.

El plugin no hace nada cuando no hay ningún coderemote en ejecución, o cuando la carpeta de la sesión no está compartida: Claude Code funciona entonces exactamente igual que sin él.

Codex

Codex 0.139 o posterior también funciona:

$ coderemote setup codex

Luego abre Codex una vez, escribe /hooks y confía en los hooks de Code Remote: Codex ejecuta los hooks de un plugin solo después de que los hayas revisado. Las sesiones de Codex aparecen en la pestaña Agents con la etiqueta Codex.

Una diferencia: Codex muestra su propia solicitud de aprobación solo después de que el hook se aparta. Así que mientras usas el ordenador (o tienes la máquina abierta en la app), Codex pregunta en su terminal como de costumbre y la app muestra "Answer on your computer"; cuando estás fuera, la solicitud espera a tu teléfono, con una notificación, hasta diez minutos antes de que Codex pregunte en el terminal. Codex no tiene "permitir siempre" desde un hook.

La pestaña Agents

Lista las sesiones de la máquina, agrupadas en Needs You (esperando una respuesta), Working, Idle y Ended; la pestaña muestra cuántas te necesitan. Abre una para ver qué hizo: tus prompts, las respuestas de Claude y cada herramienta que ejecutó. Los comandos se muestran con su salida, las ediciones de archivos como las líneas que cambian (toca para ver el cambio completo o el archivo), y las lecturas abren el archivo.

Una sesión iniciada en un terminal de la app tiene Open in Terminal, para escribir en ella directamente. Las sesiones que iniciaste en el ordenador muestran la misma cronología.

Las sesiones viven en la memoria de coderemote: detener coderemote up borra la lista, y las sesiones terminadas desaparecen tras un día.

Responder desde el teléfono

Cuando Claude pide permiso para ejecutar algo, o te hace una pregunta, aparece una tarjeta al final de la sesión:

  • Allow o Deny. El menú ⋯ tiene las mismas opciones de "permitir siempre" que ofrece Claude Code en el ordenador, y Deny with Message para decirle a Claude qué hacer en su lugar.
  • Para una pregunta, toca una respuesta, o Other… para escribir una.

La solicitud también sigue abierta en el ordenador. Gana quien responda primero: si respondes en el ordenador, la tarjeta (y su notificación) desaparece en el teléfono. Una solicitud que nadie responde desde el teléfono en una hora se deja al ordenador.

Inicia y dirige sesiones

Toca + en la pestaña Agents para iniciar un agente de programación en el ordenador. Elige el Agent (Claude Code, o Codex una vez configurado) y la Folder: abre la carpeta compartida, donde entras en subcarpetas, las filtras por nombre y tocas Use This Folder. Luego:

  • Para Claude Code, un modelo y cómo pide permiso (Ask First, Accept Edits, Plan Only o Auto).
  • Para Codex, un modelo de los que ofrece el propio Codex (Default es el de la configuración de Codex), y si puede Ask before running outside the sandbox. Si está desactivado, Codex rechaza lo que su sandbox no permite, sin preguntar.

La sesión se ejecuta en un terminal de la app, así que puedes escribirle desde el cuadro de mensaje de la sesión:

  • Escribe un prompt y envíalo; mientras Claude trabaja, lo que envías espera su turno, como en el ordenador. Stop lo interrumpe (como Esc).
  • + adjunta fotos, vídeos, archivos, una foto de la cámara o una imagen copiada. Van a ~/.coderemote/uploads/ en el ordenador (fuera de tu proyecto, se borran tras una semana), y Claude ve las imágenes como imágenes; de otros archivos recibe su ruta.
  • El menú ⚡ tiene Next Permission Mode (Shift+Tab), /compact, /clear, /model y Open in Terminal (Codex no tiene modos de permisos que alternar ni /clear). En el terminal, Chat en el menú … te devuelve.
  • Una sesión terminada ofrece Resume Here, que continúa la conversación en un terminal nuevo.

Una sesión que iniciaste en un terminal del ordenador se puede seguir y responder aquí pero no escribir en ella, porque no es el terminal de la app; reanúdala aquí cuando termine.

Notificaciones

Actívalas por ordenador en la información de la máquina (mantenla pulsada en la lista de máquinas, o Machine Info en el menú de una pestaña): Necesita una respuesta y Terminó una tarea larga (una que tardó un minuto o más), con un botón de prueba.

Mantén pulsada una notificación de permiso para Permitir o Denegar sin abrir la app (tras Face ID); una pregunta sencilla ofrece sus respuestas del mismo modo. No se envía nada mientras usas el ordenador (en un Mac) o tienes la máquina abierta en la app.

Cómo funciona

El plugin ejecuta coderemote hook en cada evento de Claude Code (un prompt, una llamada a una herramienta, una respuesta, una solicitud de permiso). Entrega el evento al coderemote que comparte la carpeta de la sesión, en el mismo ordenador, autenticado con un secreto que nunca sale de él. Una solicitud de permiso espera allí una respuesta desde el teléfono mientras Claude Code muestra la suya como de costumbre.

Las notificaciones salen de tu ordenador a través de un relay que añade la clave push de Apple de la app; su contenido está cifrado para tu iPhone, así que ni el relay ni Apple pueden leerlo, y el relay no guarda nada. Consulta la política de privacidad.
