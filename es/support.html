Soporte

Solemos responder en unos días.

Escribe a trantienthanh2412@gmail.com o abre un issue en GitHub. Incluye tu versión de iOS, el sistema de tu ordenador, tu versión de coderemote (coderemote --version) y qué estabas haciendo.

Primeros pasos

En tu ordenador (macOS, Windows 10/11 o Linux), instala coderemote con el script de instalación, npm o Homebrew (todas las formas, para cada sistema) y comparte una carpeta:

$ curl -fsSL https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.sh | sh
$ cd ~/projects/my-app && coderemote up

Después descarga la App desde la App Store y escanea el código QR con la cámara del iPhone, o con el botón + de la App. La primera ejecución descarga la CLI de Dev Tunnels de Microsoft y te pide iniciar sesión con GitHub (o ejecuta antes coderemote login --microsoft para usar una cuenta de Microsoft).

Preguntas frecuentes

La App no puede conectarse a mi ordenador.

Comprueba que coderemote up sigue en marcha en el ordenador y que este está encendido y con conexión. Ejecuta coderemote status para ver los agentes en ejecución. Si iniciaste sesión con otra cuenta en el teléfono, vuelve a iniciarla con la misma cuenta de GitHub o Microsoft que usa el ordenador.

He perdido mi teléfono, o se filtró un enlace de emparejamiento.

Ejecuta coderemote rotate-token en el ordenador. Todos los dispositivos emparejados pierden el acceso de inmediato; vuelve a emparejar escaneando el nuevo código QR.

¿Sobreviven las sesiones de terminal cuando mi teléfono se bloquea?

Sí. Las sesiones siguen ejecutándose en el ordenador con su salida reciente. Vuelve a abrir la App y se reconectan. Termínalas con coderemote kill.

coderemote dice que mi cuenta de Dev Tunnels ya tiene 10 túneles.

Es el máximo que una cuenta puede conservar. Ejecuta coderemote tunnels para verlos y elimina los que ya nadie usa, como los de un ordenador antiguo, con coderemote tunnels delete <id>. Consulta tunnels.

¿Puedo compartir más de una carpeta?

De momento, de una en una. Comparte una carpeta superior para llegar a varios proyectos; la pestaña Git encuentra todos los repositorios que contiene.

¿Mi código pasa por sus servidores?

No. Code Remote no tiene servidores. El tráfico pasa por el relé de Microsoft Dev Tunnels entre tu teléfono y tu ordenador, cifrado de extremo a extremo, de modo que el relé solo reenvía datos cifrados (la reproducción de medios y la subida de archivos son la excepción). Consulta la Política de privacidad.

Problemas de seguridad

Por favor, no informes de vulnerabilidades en issues públicos. Sigue en su lugar la política de seguridad.
