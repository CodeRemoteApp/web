你的电脑,装进口袋。

在 iPhone 上浏览文件、使用 git、运行终端并打开开发服务器，只需一条命令：npx coderemote up。端到端加密。无需 SSH 密钥、无需端口转发、无需 VPN。

开始使用 下载于App Store 立即获取Google Play
# on your computer

一条命令。全部设置就这些。

其他工具要你下载桌面应用、在两台设备上都配置 VPN,或设置 SSH 服务器和密钥。只要电脑上已有 Node.js,Code Remote 就只需要一行命令。

npx coderemote up

无需桌面应用

电脑上无需下载、安装或保持更新任何东西。npx 运行完就不留下任何痕迹。

无需 VPN

代理 (agent) 通过私有隧道向外连接，并经过端到端加密。无需在手机的网络中安装任何东西，也无需加入任何网络。

无需 SSH

无需开启服务器,无需复制密钥,无需转发端口,无需修改防火墙规则。

查看完整对比,包括什么情况下其他工具更合适。

安装到你的电脑上,在 iPhone 上获取应用。

macOS 和 Linux

粘贴到终端中。没有 Node.js?它会专门为 coderemote 下载一份。

curl -fsSL https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.sh | sh

Windows

粘贴到 Windows 10 或 11 的 PowerShell 中。没有 Node.js?它会专门为 coderemote 下载一份。

irm https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.ps1 | iex

npm

适用于任何装有 Node.js 22 或更高版本的系统。

npm install -g coderemote

Homebrew

适用于 macOS 和 Linux。

brew install coderemoteapp/tap/coderemote
在 App Store 下载 免费的 iPhone 版 Code Remote 应用,用来扫描二维码并配对。

想要长期安装?在项目文件夹中运行 coderemote up,然后用应用扫描二维码。更新、卸载等内容请见安装指南。

想在 Android 上使用?

Code Remote 目前只支持 iPhone。如果你想在 Android 上使用,请留下邮箱。如果需要的人够多,我们就会开发 Android 应用,并第一时间通知你。

我们只会用你的邮箱通知你 Android 应用的消息。请参阅隐私政策。

保持工作不中断所需的一切。

文件

在你共享的文件夹中浏览、打开、编辑、创建、重命名和删除文件。

Git

查看变更和 diff,暂存、提交、拉取、推送并阅读历史,覆盖文件夹中的每个仓库。

终端

真正的 shell(Windows 上是 PowerShell),配有 Ctrl、Tab、Esc 和方向键的按键栏。手机休眠时会话仍会继续运行,所以耗时较长的构建和编程智能体都不会中断。

端口

查看哪些服务器正在监听、是哪个终端启动的,并停掉卡在 3000 端口的那个。

预览与分享

轻点一下,即可通过专属的私有隧道在手机上打开开发服务器。想听听别人的意见?分享一个一小时或一天后失效的公开链接。

请求

查看到达开发服务器的每个请求,包括请求头和请求体。可按类型或路径筛选,还能让你的编程智能体在终端里读取它们。

隐私,从设计开始。

没有我们的服务器

你的手机直接与你的电脑通信。Code Remote 不运行任何后端,也没有账号。

不收集任何数据

应用和 CLI 都没有统计分析、没有追踪、没有广告。你的文件和命令不会到达我们这里。

开源

电脑端是遵循 AGPL 的自由软件。每一行代码都可以在 GitHub 上阅读。

端到端加密

二维码中带有你电脑的密钥。手机和电脑之间的一切都会加密，隧道的中继只能转发密文。

每部手机一个密钥

每部 iPhone 在自己的 Secure Enclave 中保存自己的密钥。在电脑上用一条命令移除其中一部，其他设备照常使用。

命令需要 Face ID

打开终端或启动编程代理前会先要求 Face ID。严格程度以及一次验证的有效时长，可以按每台电脑选择。
