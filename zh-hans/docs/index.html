简介

用 iPhone 连接你的电脑:文件、git、真正的终端和你的开发服务器。电脑上一条命令,手机上扫一下。

它是什么

Code Remote 有两部分:电脑上的命令行工具 coderemote,以及 iPhone 应用。你不需要 SSH、开放端口、VPN 或桌面应用。不确定是否适合?看看它与 Tailscale、Termius 和 Orca 的对比。

工作原理

  1. 启动智能体。在项目文件夹中运行 coderemote up(不安装的话运行 npx coderemote up)。一个小型智能体会在你的电脑上启动,只监听 127.0.0.1。
  2. 它向外连接。智能体通过私有的 Microsoft Dev Tunnel 发布自己。你的网络无需开放任何东西,在 NAT、防火墙和酒店 Wi-Fi 后面也能工作。
  3. 配对手机。扫描二维码。只有你的 GitHub 或 Microsoft 账号才能通过中继，每个请求还需要保存在 iPhone 钥匙串中的配对令牌，二维码还带有电脑的密钥，因此应用会对一切进行端到端加密：中继只转发密文。
