Code Remote 与常见方式的对比。

要从手机连接你的开发机,大多数工具都需要你在电脑上下载应用、配置 VPN 或设置 SSH。Code Remote 只需要一条命令和一次二维码扫描。

npx coderemote up

需要 Node.js 22 或更高版本。没有 Node?安装脚本会专门为 coderemote 获取一份。首次运行会让你用 GitHub 或 Microsoft 登录一次。

为什么选择 Code Remote

  • 最短的路径。一条命令,一次扫描。其他工具需要安装两三样东西、两端各一个账号,以及密钥或网络设置。
  • 无需维护。无需一直保持连接的 VPN,无需加固的 SSH 服务器,无需轮换的密钥,无需更新的桌面应用。
  • 为手机而做。文件浏览器、git 审阅、终端按键栏和一键预览,而不是把终端硬塞进小屏幕。
  • 隐私优先的设计。智能体只监听 127.0.0.1,中间没有任何 Code Remote 服务器。了解其工作原理。

如果你要管理很多台机器或服务器,Tailscale 和 Termius 是正确的选择,Code Remote 并不能在这方面取代它们。Orca 是你在办公桌前运行智能体的地方,而 Code Remote 是你离开时连接机器的方式,所以两者可以并存。

什么时候其他工具更合适

  • 你需要完整的桌面。Code Remote 面向开发者的工作:文件、git、终端、开发服务器。需要设计软件或图形界面安装程序时,请使用远程桌面应用。
  • 你已经到处在用 VPN 和 SSH。如果已经配置好并且用得顺手,在其上使用终端应用完全没问题。Code Remote 适合那些根本不想配置的时候。
  • 你用的不是 iPhone。Code Remote 应用只面向 iPhone。其他设备目前只能使用上面的工具(想要 Android 版?)。

依然保持简单的地方

代理只监听 127.0.0.1，并通过私有的 Microsoft Dev Tunnel 对外发布。只有你的 GitHub 或 Microsoft 账号能通过，手机和电脑之间的一切都用二维码中的密钥进行端到端加密，每部手机都用其 Secure Enclave 中自己的密钥登录。了解工作原理。
