支持

我们通常会在几天内回复。

发送邮件至 trantienthanh2412@gmail.com,或在 GitHub 上提交 issue。请附上你的 iOS 版本、电脑系统、coderemote 版本(coderemote --version)以及你当时在做什么。

快速开始

在你的电脑上(macOS、Windows 10/11 或 Linux),用安装脚本、npm 或 Homebrew 安装 coderemote(各系统的所有安装方式),然后共享一个文件夹:

$ curl -fsSL https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.sh | sh
$ cd ~/projects/my-app && coderemote up

然后从 App Store 获取应用,用 iPhone 相机或应用里的 + 按钮扫描二维码。首次运行会下载 Microsoft 的 Dev Tunnels CLI,并要求你用 GitHub 登录(如要使用 Microsoft 账号,请先运行 coderemote login --microsoft)。

常见问题

应用无法连接到我的电脑。

确认电脑上的 coderemote up 仍在运行,并且电脑处于唤醒和联网状态。运行 coderemote status 查看正在运行的智能体。如果你在手机上用了不同的账号登录,请用电脑所使用的同一个 GitHub 或 Microsoft 账号重新登录。

我丢了手机,或者配对链接泄露了。

在电脑上运行 coderemote rotate-token。所有已配对的设备会立即失去访问权限;扫描新的二维码重新配对即可。

手机锁屏后,终端会话还在吗?

会。会话连同最近的输出会继续在电脑上运行。重新打开应用后它们会重新连接。用 coderemote kill 结束它们。

coderemote 提示我的 Dev Tunnels 账号已经有 10 个隧道了。

这是一个账号最多可以保留的数量。运行 coderemote tunnels 查看它们,并用 coderemote tunnels delete <id> 删除不再使用的,例如旧电脑留下的。请参阅 tunnels。

可以共享多个文件夹吗?

目前一次一个。共享上级文件夹即可访问多个项目;Git 标签页会找到其中的每个仓库。

我的代码会经过你们的服务器吗?

不会。Code Remote 没有服务器。流量经由 Microsoft 的 Dev Tunnels 中继在手机和电脑之间传输，并且是端到端加密的，中继只转发密文（媒体播放和文件上传除外）。请参阅隐私政策。

安全问题
