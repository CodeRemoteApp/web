Code Remote vs. the usual ways in.

To reach your dev machine from a phone, most tools want you to download an app on the computer, set up a VPN, or configure SSH. Code Remote needs one command and one QR scan.

npx coderemote up

Needs Node.js 22 or newer. No Node? The install script fetches one for coderemote alone. The first run asks you to sign in once with GitHub or Microsoft.

Why Code Remote

  • The shortest path. One command and one scan. The others need two or three installs, an account on each side, and keys or network settings.
  • Nothing to maintain. No VPN to keep connected, no SSH server to harden, no keys to rotate, no desktop app to update.
  • Made for the phone. A file browser, git review, key bar for the terminal and one-tap previews, instead of a terminal squeezed onto a small screen.
  • Private by design. The agent listens on 127.0.0.1 only, and no Code Remote server sits in between. Read how it works.

Tailscale and Termius are the right choice if you manage many machines or servers, and Code Remote does not replace them for that. Orca is where you run agents at your desk, and Code Remote is how you reach your machine when you are away from it, so the two can sit side by side.

When another tool is the better fit

  • You need the full desktop. Code Remote is for developer work: files, git, terminal, dev servers. For a design app or a GUI installer, use a remote desktop app.
  • You already run a VPN and SSH everywhere. If that is set up and you like it, a terminal app over it works fine. Code Remote is for when you would rather not set it up at all.
  • It is not an iPhone. The Code Remote app is for iPhone. Anything else has to use the tools above.

What stays simple

The agent listens on 127.0.0.1 only and publishes itself through a private Microsoft Dev Tunnel. Only your GitHub or Microsoft account gets through, and every request also needs the pairing token kept in the iPhone Keychain. Read how it works.
