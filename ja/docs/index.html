はじめに

iPhone から、あなたのコンピューターへ: ファイル、git、本物のターミナル、開発サーバー。コンピューターでコマンドを 1 つ、iPhone で QR をひとつ読み取るだけ。

どんなものか

Code Remote は 2 つの部分でできています。コンピューター上のコマンドラインツール coderemote と、iPhone アプリです。SSH、開いたポート、VPN、デスクトップアプリは必要ありません。合うか分からない場合は、Tailscale、Termius、Orca との比較をご覧ください。

仕組み

  1. エージェントを起動。プロジェクトのフォルダで coderemote up を実行します(インストールせずに npx coderemote up でも可)。小さなエージェントがコンピューター上で起動し、127.0.0.1 だけで待ち受けます。
  2. 外向きに接続します。エージェントはプライベートな Microsoft Dev Tunnel を通して自分自身を公開します。ネットワークで何かを開ける必要はなく、NAT、ファイアウォール、ホテルの Wi-Fi の内側でも動きます。
  3. iPhone をペアリングします。QR コードをスキャンします。リレーを通れるのはあなたの GitHub または Microsoft アカウントだけで、すべてのリクエストには iPhone のキーチェーンに保存されたペアリングトークンも必要です。さらに QR コードにコンピューターの鍵が含まれるため、アプリはすべてをエンドツーエンドで暗号化し、リレーは暗号文を中継するだけです。
