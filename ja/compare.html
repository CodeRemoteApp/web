Code Remote と、これまでの方法の比較。

iPhone から開発マシンに届くようにするには、多くのツールがコンピューターへのアプリのダウンロード、VPN の設定、SSH の構成を求めます。Code Remote に必要なのは、コマンド 1 つと QR の読み取り 1 回です。

npx coderemote up

Node.js 22 以降が必要です。Node がなくても、インストールスクリプトが coderemote 専用に 1 つ取得します。初回はいちど GitHub または Microsoft でサインインします。

Code Remote を選ぶ理由

  • いちばんの近道。コマンド 1 つと読み取り 1 回。他のツールは 2〜3 個のインストール、双方のアカウント、鍵やネットワーク設定が必要です。
  • 保守不要。つなぎ続ける VPN も、堅牢化する SSH サーバーも、更新する鍵も、アップデートするデスクトップアプリもありません。
  • iPhone のために作られています。小さな画面に押し込んだターミナルではなく、ファイルブラウザ、git レビュー、ターミナル用のキーバー、ワンタップのプレビューを備えています。
  • 設計からプライベート。エージェントは 127.0.0.1 だけで待ち受け、間に Code Remote のサーバーはありません。仕組みを読む。

多数のマシンやサーバーを管理するなら Tailscale や Termius が適しており、Code Remote はその用途の代わりにはなりません。Orca は机でエージェントを動かす場所、Code Remote は席を離れているときにマシンへ届く手段なので、両方を併用できます。

他のツールのほうが向いているとき

  • デスクトップ全体が必要な場合。Code Remote は開発者の作業(ファイル、git、ターミナル、開発サーバー)のためのものです。デザインアプリや GUI のインストーラーには、リモートデスクトップアプリを使ってください。
  • すでに VPN と SSH をあちこちで使っている場合。設定済みで気に入っているなら、その上でターミナルアプリを使えば問題ありません。Code Remote は、そもそも設定したくない人のためのものです。
  • iPhone ではない場合。Code Remote アプリは iPhone 向けです。それ以外は、上のツールを使ってください。

シンプルなままの部分

エージェントは 127.0.0.1 だけで待ち受け、非公開の Microsoft Dev Tunnel を通して公開されます。通れるのはあなたの GitHub または Microsoft アカウントだけで、スマートフォンとコンピューターの間はすべて QR コードの鍵でエンドツーエンド暗号化され、各スマートフォンは Secure Enclave にある自分の鍵でサインインします。仕組みを読む。
