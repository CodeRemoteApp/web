あなたのコンピューターを、ポケットに。

ファイルの閲覧、git、ターミナル、開発サーバーを iPhone から。コマンドは 1 つだけ: npx coderemote up。エンドツーエンド暗号化。SSH 鍵もポート転送も VPN も不要です。

コマンドは 1 つ。セットアップはそれだけ。

他のツールでは、デスクトップアプリのダウンロード、両方のデバイスへの VPN 設定、SSH サーバーと鍵の構成が必要です。コンピューターに Node.js があれば、Code Remote は 1 行で済みます。

npx coderemote up

デスクトップアプリ不要

コンピューターにダウンロードもインストールも更新も要りません。npx が実行し、何も残しません。

VPN 不要

エージェントは非公開のトンネルを通して外向きに接続し、通信はエンドツーエンドで暗号化されます。スマートフォンのネットワークに入れるものも、参加するものもありません。

SSH 不要

サーバーの有効化も、鍵のコピーも、ポート転送も、ファイアウォールの設定変更も不要です。

詳しい比較を見る。他のツールのほうが向いているケースも載せています。

コンピューターにインストールし、iPhone にアプリを入れましょう。

macOS と Linux

ターミナルに貼り付けます。Node.js がなくても大丈夫。coderemote 専用に 1 つダウンロードします。

curl -fsSL https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.sh | sh

Windows

Windows 10 または 11 の PowerShell に貼り付けます。Node.js がなくても大丈夫。coderemote 専用に 1 つダウンロードします。

irm https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.ps1 | iex

npm

Node.js 22 以降があればどの環境でも使えます。

npm install -g coderemote

Homebrew

macOS と Linux 向け。

brew install coderemoteapp/tap/coderemote
App Store からダウンロード iPhone 用の無料アプリ Code Remote。QR コードを読み取ってペアリングします。

常用したい場合は、プロジェクトのフォルダで coderemote up を実行し、アプリで QR コードを読み取ってください。アップデートやアンインストールなどはセットアップガイドにあります。

Android で使いたいですか?

Code Remote は今のところ iPhone 専用です。Android で使いたい方は、メールアドレスを残してください。希望が多ければ Android アプリを作り、真っ先にお知らせします。

メールアドレスは Android アプリのお知らせのためだけに使います。プライバシーポリシーをご覧ください。

作業を続けるために必要なものを、すべて。

ファイル

共有したフォルダ内のファイルを、閲覧・開く・編集・作成・名前変更・削除できます。

Git

フォルダ内のすべてのリポジトリで、変更や差分の確認、ステージ、コミット、プル、プッシュ、履歴の閲覧ができます。

ターミナル

本物のシェル(Windows では PowerShell)と、Ctrl・Tab・Esc・矢印キーのキーバー。iPhone がスリープしてもセッションは動き続けるので、長いビルドやコーディングエージェントも止まりません。

ポート

どのサーバーが待ち受けているか、どのターミナルが起動したかを確認し、ポート 3000 で止まっているものを停止できます。

プレビューと共有

開発サーバーを、専用のプライベートトンネル経由でタップひとつで iPhone に表示。誰かに見てもらいたいときは、1 時間または 1 日で終了する公開リンクを共有できます。

リクエスト

開発サーバーに届いたリクエストを、ヘッダーと本文まで確認できます。種類やパスで絞り込め、コーディングエージェントがターミナルから読むこともできます。

設計から、プライベート。

私たちのサーバーはありません

iPhone はあなたのコンピューターと直接つながります。Code Remote はバックエンドを持たず、アカウントもありません。

何も収集しません

アプリにも CLI にも、分析、トラッキング、広告はありません。ファイルやコマンドが私たちに届くことはありません。

オープンソース

コンピューター側は AGPL のフリーソフトウェアです。コードはすべて GitHub で読めます。

エンドツーエンド暗号化

QR コードにはコンピューターの鍵が入っています。スマートフォンとコンピューターの間はすべて暗号化されるので、トンネルのリレーが中継するのは暗号文だけです。

端末ごとに 1 つの鍵

iPhone ごとに自分の鍵を Secure Enclave に持ちます。コンピューターから 1 つのコマンドで 1 台を外せて、ほかの端末はそのまま使えます。

コマンドには Face ID

ターミナルを開くときやコーディングエージェントを起動するときは、まず Face ID を求めます。厳しさと、1 回の確認がどれだけ続くかは、コンピューターごとに選べます。
