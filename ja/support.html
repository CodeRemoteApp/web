はじめに

コンピューター(macOS、Windows 10/11、Linux)に、インストールスクリプト、npm、Homebrew のいずれかで coderemote をインストールし(各システムでのすべての方法)、フォルダを共有します:

$ curl -fsSL https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.sh | sh
$ cd ~/projects/my-app && coderemote up

次に、iPhone のカメラ、またはアプリの + ボタンで QR コードを読み取ります。初回は Microsoft の Dev Tunnels CLI がダウンロードされ、GitHub でのサインインが求められます(Microsoft アカウントを使うには、先に coderemote login --microsoft を実行)。

よくある質問

アプリがコンピューターに接続できません。

コンピューターで coderemote up が動いていること、コンピューターが起動していてオンラインであることを確認してください。coderemote status で実行中のエージェントを確認できます。iPhone で別のアカウントでサインインしている場合は、コンピューターと同じ GitHub または Microsoft アカウントでサインインし直してください。

iPhone を紛失した、またはペアリングリンクが漏れました。

コンピューターで coderemote rotate-token を実行してください。ペアリング済みのすべてのデバイスがただちにアクセスできなくなります。新しい QR コードを読み取って、もう一度ペアリングしてください。

iPhone をロックしてもターミナルのセッションは残りますか?

はい。セッションは直近の出力とともにコンピューター上で動き続けます。アプリを開き直せば再接続されます。終了するには coderemote kill を使います。

coderemote が、Dev Tunnels アカウントにすでに 10 個のトンネルがあると表示します。

これがアカウントで保持できる上限です。coderemote tunnels で一覧を確認し、古いコンピューターのものなど、使われていないものを coderemote tunnels delete <id> で削除してください。tunnels を参照。

複数のフォルダを共有できますか?

今のところ一度に 1 つです。複数のプロジェクトに届かせたいときは親フォルダを共有してください。Git タブがその中のすべてのリポジトリを見つけます。

コードは御社のサーバーを経由しますか?

いいえ。Code Remote にはサーバーがありません。通信は暗号化されたまま、Microsoft の Dev Tunnels リレーを通って iPhone とコンピューターの間を行き来します。プライバシーポリシーをご覧ください。

セキュリティの問題

脆弱性は公開の issue に報告しないでください。代わりにセキュリティポリシーに従ってください。
