Support

We usually reply within a few days.

Email trantienthanh2412@gmail.com, or open an issue on GitHub. Please include your iOS version, your computer's system, your coderemote version (coderemote --version) and what you were doing.

Getting started

On your computer (macOS, Windows 10/11 or Linux), install coderemote with the install script, npm or Homebrew (every way, for each system), then share a folder:

$ curl -fsSL https://raw.githubusercontent.com/CodeRemoteApp/coderemote/main/install.sh | sh
$ cd ~/projects/my-app && coderemote up

Then get the App from the App Store and scan the QR code with your iPhone Camera, or with the + button in the App. The first run downloads Microsoft's Dev Tunnels CLI and asks you to sign in with GitHub (or run coderemote login --microsoft first to use a Microsoft account).

Common questions

The App can't connect to my computer.

Check that coderemote up is still running on the computer and that the computer is awake and online. Run coderemote status to see running agents. If you signed in with a different account on the phone, sign in again with the same GitHub or Microsoft account the computer uses.

I lost my phone, or a pairing link leaked.

Run coderemote rotate-token on the computer. Every paired device loses access immediately; pair again by scanning the new QR code.

Do terminal sessions survive when my phone locks?

Yes. Sessions keep running on the computer with their recent output. Reopen the App and they reattach. End them with coderemote kill.

coderemote says my Dev Tunnels account already has 10 tunnels.

That's the most an account may keep. Run coderemote tunnels to see them, and delete the ones nothing uses any more, such as an old computer's, with coderemote tunnels delete <id>. See tunnels.

Can I share more than one folder?

One at a time for now. Share a parent folder to reach several projects; the Git tab finds every repository inside it.

Does my code go through your servers?

No. Code Remote has no servers. Traffic passes through Microsoft's Dev Tunnels relay between your phone and your computer, encrypted end to end so the relay only forwards ciphertext (media playback and file uploads are the exception). See the Privacy Policy.

Security issues

Please don't report vulnerabilities in public issues. Follow the security policy instead.
